# Security

Please don't report security issues in public issues.

Use GitHub's private reporting instead: the **Report a vulnerability** button under this repo's Security tab. Include steps to reproduce. Reports without a working reproduction will be closed.

This matters more than usual here. Claude Code mods run with the player's full permissions, so a bug in a game can affect someone's machine, and the game server is open to the internet.

We'll acknowledge reports within a few days and keep you updated until a fix ships.

Supported versions: the latest release of each game and of the server.
